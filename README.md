# Breast Cancer Prediction — Data Cleaning and Preprocessing

## Objective
To clean and prepare the Breast Cancer Wisconsin Diagnostic
dataset for machine learning.

## Dataset
Breast Cancer Wisconsin Diagnostic dataset from Scikit-learn.

The dataset contains 569 records and 30 numerical measurement
features, along with a target label.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Tasks Completed
1. Imported and explored the dataset.
2. Checked missing values.
3. Demonstrated median imputation.
4. Encoded categorical diagnosis labels.
5. Standardized numerical features.
6. Visualized potential outliers using a boxplot.
7. Detected and removed potential outliers using the IQR method.
8. Visualized the diagnosis distribution.

## Key Learning Outcomes
- Data cleaning
- Missing-value handling
- Categorical encoding
- Feature scaling
- Outlier detection
- Data visualization

## Important Note
The dataset is used for educational purposes only.
The notebook demonstrates preprocessing techniques and
does not provide a medical diagnosis.
